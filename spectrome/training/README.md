# Shared graph-filter training

`filters.py` contains `generate_training_data`, `FeGraphMLP`, and
`predict_spectra`. `train.py` coordinates training and saves the selected model.
The existing Torch forward file owns the SGM equations.

## Prepare and save

`generate_training_data(subjects, frequencies_hz, output_path,
preprocessing_id=...)` accepts explicitly paired records. Each record supplies:

- `subject_id`: unique string.
- `brain`: model-order `reducedConnectome` and `distance_matrix` in millimeters.
- `parameters`: the seven fixed, named SGM parameters.
- `empirical_meg`: raw nonnegative observed spectra `[R, F]`.
- `observed_regions`: ordered model-node indices corresponding to MEG rows.
- `split`: `train`, `validation`, or `test`.
- `mapping_verified`: True only after subject and region alignment are verified.
- `provenance`: JSON-compatible source paths/hashes, original record indices,
  and the evidence supporting alignment.

The saved CPU tensors contain the entire empirical spectrum, fixed parameters,
and one prepared graph per frequency, including all eigenvalues and selected
eigenvectors. Graph preparation runs without gradients. Learning evaluates the
response with gradients; it never recomputes eigenpairs.

## Model and prediction

```python
model = FeGraphMLP(hidden_sizes=chosen_widths, omega_scale=chosen_scale)
Fe_graph = model(cache["omega"])
raw_prediction = predict_spectra(cache["subjects"][0], Fe_graph)
analytical_prediction = predict_spectra(cache["subjects"][0])
```

The input is omega in rad/s, divided by a caller-specified fixed scale. Two real
outputs form one complex graph-filter value per frequency. The same values are
shared across subjects. Local analytical Fe remains unchanged.

## Train and save

From the repository root, `python -m spectrome.training.train --help` lists the
required cache/output paths and explicit settings: `--hidden-sizes`,
`--omega-scale`, `--epochs`, `--learning-rate`, and `--seed`.

The CPU float64 loop uses Adam and one full training-cohort step per epoch.
Loss is one minus mean subject spectral correlation, with equal region weight
within each subject. Prediction and empirical spectra undergo magnitude,
`[1, 2, 5, 2, 1]/11` zero-padded smoothing, square root, and frequency demeaning.
A recorded 1e-12 floor before square root keeps gradients finite at zero;
near-constant or nonfinite regional spectra fail rather than being dropped.

Validation mean correlation selects the checkpoint; test subjects are scored
after selection. Checkpoints include `state_dict`, architecture/scaling,
training settings, history, split identities/provenance, raw predictions,
learned filter values, and analytical/learned subject correlations.

```python
checkpoint = torch.load(model_path, map_location="cpu", weights_only=True)
model = FeGraphMLP(**checkpoint["model_config"])
model.load_state_dict(checkpoint["state_dict"])
model.eval()
```

This compares filter transfer conditional on saved subject-fitted parameters.
It does not establish prediction without subject-specific MEG calibration.
